# Image Library (Page Editor)

## What It Is

A store of images you upload once and then apply to a **Hero** or **Text** block on any page of your website. It lives inside the page editor but is shared by every page of your site.

## Open It

**My Website** > **Manage Pages** > **Edit** a page. The **Image Library** card sits above the content blocks.

## Upload an Image

1. Choose a file: JPG, PNG, GIF or WebP, up to 8 MB.
2. Click **Upload Image**. The thumbnail appears in the library.

Uploads count toward the storage pool you share with Documents, article covers, gallery photos and client-portal files. If an upload would exceed your limit the message tells you the current usage.

## Put an Image on a Block

Two ways:

- **From the library card.** Under **Apply uploaded image to**, pick the block (only Hero and Text blocks on this page are listed), then click **Use** under the image. It saves to that block straight away; on a published page the change is live immediately. No need to click Save Block for the image.
- **From inside the block.** Open the block, and under **Image (optional)** choose from **My uploaded images** or the shared **starter banners**, with a live preview. This choice is saved when you click **Save Block**.

Hero blocks also have layout, height, focal-point and overlay controls for the image.

## Starter Banners

**Browse shared starter banners** offers ready-made images by category. Pick a destination block and click **Use this banner** to apply one the same way as an uploaded image.

## Remove an Image

**Remove** deletes the image from the library and clears it from **every block on every page** of your site that uses it. There is no undo, so check where an image is used before removing it. The file itself is kept if something else still references it, such as an article cover.

## What the Library Does Not Do

- Blog and Article Page blocks take their images from each article's own cover, set under **Articles**. The library does not affect them.
- Blocks other than Hero and Text do not show a library image, which is why they are not offered as destinations.
- Uploaded images are served from public addresses. Anyone with the link can view them, so do not upload anything confidential.

## Package Availability

The page editor, and with it the Image Library, needs the Instant Website feature in your package.
